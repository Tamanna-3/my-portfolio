# Tamanna Bhatt Portfolio — Refined Blue Scrapbook Version

## What changed in this revision

- Main display typography changed to Sora for a cleaner modern tech feel.
- Palette shifted toward navy, sky blue and soft blue accents with much less purple.
- Removed the decorative side timeline strip and other unnecessary divider-strip styling.
- Education copy cleaned up and date formatting changed to plain text.
- Skills reorganized and expanded with MySQL, Mergo, CloudHQ, Canva, CapCut and VN.
- Simtrak experience is now a smaller compact card using the supplied Simtrak logo.
- BharatCares / IBM SkillsBuild / AICTE internship card is compact and includes organization logo marks.
- Removed the "where Carevo started" note.
- Replaced the old achievement strip with a compact "Beyond Code" block.
- Project section redesigned into smaller project cards.
- Carevo AI now uses four supplied screenshots in a compact gallery.
- Certificates are smaller and the available certificate cards open their PDF files in a new browser tab.
- Contact copy and CTA have been refreshed.
- Footer expanded with navigation, current focus, contact CTA and scrapbook personality.
- Added Uiverse-inspired pill CTA interactions using lightweight CSS only.

## Run locally

From this folder:

```bash
python -m http.server 5500
```

Then open:

`http://127.0.0.1:5500/index.html`

You can also use VS Code Live Server.

## GitHub Pages

This remains a static HTML/CSS/JavaScript project. Upload the contents to the existing repository and keep `index.html` at the repository root used by GitHub Pages.

## Note about partner logos

The BharatCares, IBM and AICTE logo images in the internship card are loaded from public web sources. The supplied Simtrak logo is stored locally in `assets/img/simtrak-logo.png`.

- Reduced the footer portrait and footer height.
