Run Locally

Option 1 — VS Code Live Server

Open the project folder in VS Code and launch index.html using the Live Server extension.

Option 2 — Python Local Server

From the project folder:

python -m http.server 5500

Then open:

http://127.0.0.1:5500/index.html

Deploy to GitHub Pages

This portfolio is deployed from:

Tamanna-3/my-portfolio

Deployment Steps

Push the latest files to the main branch.

Open the repository on GitHub.

Go to Settings → Pages.

Under Build and deployment, choose Deploy from a branch.

Select:

Branch: main

Folder: / (root)

Save.

GitHub Pages will redeploy automatically after future pushes.

Updating the Portfolio

After making local changes:

git add .
git commit -m "Update portfolio"
git push origin main
