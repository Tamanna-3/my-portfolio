MisinfoX

AI-powered browser extension for real-time misinformation, scam & phishing detection

MisinfoX is an AI-assisted browser extension designed to help users verify online information instantly. When the extension is enabled, users can highlight any text on a webpage and select “Ask MisinfoX”.

The system analyzes the selected content using browser APIs and content analysis techniques to determine whether the information is misinformation, a scam, phishing attempt, or misleading content, and provides a clear risk verdict.

How it works

1. Enable Extension
2. Highlight Suspicious Text
3. Ask MisinfoX
4. AI Analysis & Risk Verdict

AAO-LO

Smart restaurant discovery platform based on food preferences, budget, and who you’re going with

AAO-LO is a decision-support web application designed to solve a common real-world problem: choosing the right restaurant for the right people.

Many users end up visiting places that don’t match their group — for example, family outings at couple-oriented cafés or friend meetups at quiet family restaurants. AAO-LO helps users avoid this mismatch by clearly categorizing restaurants based on suitability, ambience, and budget.

Key features

  • Restaurant discovery based on food type, budget, and location
  • Clear suitability tags: Family, Couples, Friends, Solo
  • Budget indicators (₹, ₹₹, ₹₹₹) for quick decision-making
  • Ambience and vibe overview for each restaurant
  • User reviews focusing on comfort, group suitability, and experience

How it works

1. Select who you’re going with
2. Filter by food & budget
3. Explore suitable restaurants
4. Read reviews & decide confidently

Tech stack

HTML • CSS • JavaScript • Responsive UI Design • API Integration

Impact

AAO-LO reduces user decision time by clearly presenting only relevant restaurant options, improving user satisfaction and minimizing poor dining choices caused by ambience mismatch.
